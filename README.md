# fHelper

Помощник для MoonLoader на Arizona RP и Rodina RP: доходы и пейдеи, уведомления на экране, бинды, заметки, интеграции, калькулятор, крафт, сканер машин.

## Установка

1. Нужны MoonLoader, SAMPFUNCS, mimgui, fAwesome5 и SAMP.Lua (samp.events).
2. Скачай [fhelp.lua](fhelp.lua) (кнопка Download raw file) и положи в папку `moonloader` игры.
3. В игре открой меню командой `/fhelp`.

## Обновления

fHelper сам проверяет эту страницу при входе в игру и подсказывает, когда вышла новая версия.
Обновить можно в меню: Настройки → Обновление, или командой `/fupdate`.
Перед заменой файл проверяется, старая версия остаётся в `moonloader\fhelp_backup`.

Файл `version.json` нужен для проверки обновлений, его скачивать не надо.
